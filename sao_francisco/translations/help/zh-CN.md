# São Francisco 帮助

São Francisco 可将音频和视频转换为文本。选择电脑上的文件或粘贴视频的公开地址。界面默认使用英语；您可以在**设置 → 界面语言**中更改，录音的转录语言不受影响。

## 入门

建议先使用一段短录音：

1. 打开**设置**，添加 OpenAI 或 Gemini API 密钥。
2. 返回**转录**。
3. 选择文件或粘贴视频地址。
4. 选择服务和模型。
5. 勾选所需的输出格式。
6. 选择目标文件夹。
7. 点击**开始转录**。

完成后，文件将保存在所选文件夹中。您也可以从**历史记录**中打开。

## 添加文件、视频或网址

在**文件**选项卡中选择一个或多个音频或视频文件。支持 MP3、WAV、M4A、MP4、MOV、MKV 和 WebM 等常见格式。

在 **YouTube 或网址**中粘贴视频的公开地址。需要登录、订阅、付费或网站特别授权的内容可能不可用。

如需利用视频已有的文字，请勾选**使用视频的可用字幕**。São Francisco 会在创建文档前去除逐步出现的重复文本。此选项默认关闭；如果希望重新转录音频，请保持关闭。

可以在网上访问的视频不一定可以自由使用。请仅转录您有权使用或已获得许可的材料。

### 检测语言

**自动检测**让服务识别说话的语言。您也可以自行指定。两种方式没有绝对优劣：指定语言可能有助于处理噪声、口音、姓名和相近语言；自动检测适用于未知语言或混合语言。此设置与界面语言不同。

## 选择模型

名称表示推荐用途：

- **经济型 — OpenAI：**适合入门和连续文本。
- **高精度 — OpenAI：**优先保证姓名和词汇准确。
- **识别说话人 — OpenAI：**尽可能区分参与者。
- **字幕与时间 — OpenAI：**提供更精确的时间戳。
- **Gemini 详细型：**生成结构化转录。
- **Gemini 经济型：**适合较大量任务的替代方案。

质量取决于录音。噪声、过响的音乐、多人同时说话、麦克风距离过远和罕见姓名都可能需要人工检查。各服务的模型及可用性可能变化。

## OpenAI 和 Gemini 密钥

API 密钥是允许 São Francisco 向所选服务发送音频的秘密凭据。创建密钥不要求您是开发者。

聊天机器人订阅与 API 使用是不同服务。例如，ChatGPT Plus 不会自动包含 OpenAI API 额度。各服务商自行管理收费、限额和模型访问权限。

São Francisco 将密钥保存在系统安全存储中，之后不会再次完整显示。

### 创建 OpenAI 密钥

1. 打开 [OpenAI 官方密钥页面](https://platform.openai.com/api-keys)。
2. 登录或创建账户。
3. 为所需项目创建密钥。
4. 密钥出现时复制它。
5. 在 São Francisco 的**设置 → OpenAI**中粘贴。
6. 点击**验证**，然后点击**保存设置**。

有效密钥仍可能没有余额、额度或所选模型的访问权限。请在 OpenAI 平台检查账单和限额。

### 创建 Gemini 密钥

1. 打开 [Gemini 官方密钥页面](https://ai.google.dev/gemini-api/docs/api-key)。
2. 登录 Google AI Studio。
3. 选择项目并创建密钥。
4. 在**设置 → Gemini**中粘贴。
5. 点击**验证**，然后点击**保存设置**。

> [!WARNING]
> 切勿在文档、截图、消息或支持请求中分享密钥。如果密钥泄露，请撤销并创建新密钥。

## 长媒体的处理方式

São Francisco 将长视频分成较小的部分，再合并成一份转录，无需一次发送整个视频。

完成的部分会被保存。中断后，您可以从**历史记录**继续，无需全部重做。所需时间取决于录音时长、网络速度和服务可用性。

## 跟踪、取消和恢复

转录时，屏幕会显示进度和当前处理的部分。

**取消**会将卡片变为**正在取消**，并在大约五秒内停止执行。已完成的部分和文件仍然可用。已经到达服务商的请求可能在取消后继续完成或产生费用。

**恢复**用于继续中断的任务。更改源文件、服务、模型或转录语言需要创建新任务。如果先前请求的结果不确定，应用会在允许新请求前提醒您，因为再次请求可能再次收费。

## 输出格式

- **TXT：**适合阅读和搜索的纯文本。
- **DOCX：**可在文字处理软件中打开的格式化文档。
- **SRT：**用于视频播放器和编辑器的字幕。
- **VTT：**主要用于网页的字幕。

DOCX 和 TXT 时间戳为可选项，默认关闭。如需使用，请在开始前勾选**在 DOCX 和 TXT 中包含时间戳**。SRT 和 VTT 始终需要时间信息。如果模型无法提供准确时间，可能需要在视频编辑器中调整字幕。

对于网络视频，São Francisco 使用视频标题作为文件名，必要时进行调整。如果同名文件已存在，会在新结果名称中添加数字。

### 使用 AI 优化

勾选**使用 AI 优化**，可在原始转录之外获得更便于阅读的第二个版本。应用会整理段落，修正标点、大小写和明显的识别错误。

优化不应摘要、翻译、修饰或补全不确定的片段。即便如此，也请特别核对姓名、数字和不清晰的内容。

DOCX 和 TXT 会分别生成**转录**和**优化文本**文件。时间戳仅保留在原始版本中。SRT 和 VTT 不会被优化步骤改写。

应用先完成、保存并导出原始转录，再执行可选优化并生成附加文件。如果优化中断，原始文件仍然可用。恢复时会复用已接受的步骤，不会自动重复结果不确定的请求。

## 费用、数据和存储

购买应用与使用 API 分开计费。São Francisco 不按转录次数收费。API 费用由 OpenAI 或 Google 根据您的账户和模型直接收取；购买应用不包含 API 额度。

每个发送的部分都可能消耗额度。恢复任务会复用已完成的工作。当数据足够时，应用显示以美元计的估算费用。很小的金额显示为**不到 0.01 美元**。如果文本全部来自已有字幕且未使用优化，则显示**无 API 费用**。

这仅是估算。免费方案、税费、折扣、中断的请求和价格变化都可能使实际账单不同。实际费用请查看 [OpenAI 用量](https://platform.openai.com/usage)或 [Google Cloud 账单](https://console.cloud.google.com/billing)。

如果服务提供可靠计数，应用还可显示 token，即衡量输入和输出的小单位。服务未提供的 token 数量不会被编造。

### 当前 API 价格

请查看官方 [OpenAI 定价](https://developers.openai.com/api/docs/pricing)和 [Gemini 定价](https://ai.google.dev/gemini-api/docs/pricing)页面。价格、计量单位、模型及免费额度可能变化。请在开始付费任务前确认。

音频会发送给所选服务。历史记录和工作文件保留在您的电脑上。结果会一直留在目标文件夹中，直到您删除。请参阅 [OpenAI 条款](https://openai.com/policies)和 [Gemini API 条款](https://ai.google.dev/gemini-api/terms)。

## 常见问题

### 密钥未被接受

**现象：**设置提示密钥无效。**处理：**核对服务商、密钥是否复制完整及是否仍有效，再检查账单、限额和模型权限。

### 文件没有音频

**现象：**任务在转录开始前结束。**处理：**打开文件并确认有声音。损坏文件或仅包含图片的视频无法转录。

### 视频地址失效

**现象：**应用无法获取视频。**处理：**更新 São Francisco 后重试。需要登录、付费、正在直播或被网站屏蔽的内容可能仍不可用。

### 处理似乎卡住

**现象：**同一部分持续运行数分钟。**处理：**长录音和繁忙的服务需要时间。如出现网络或额度提示，请取消并稍后恢复。

### 字幕不同步

**现象：**SRT 或 VTT 比说话提前或延后。**处理：**使用**字幕与时间**模型，并对照视频检查。

### 电脑空间不足

**现象：**准备或创建文件时中断。**处理：**释放磁盘空间后重试。

## 快捷键和导航

- macOS 的 `⌘N` 或其他系统的 `Ctrl+N` 打开**转录**。
- `⌘K` 或 `Ctrl+K` 打开**帮助**。
- `⌘,` 或 `Ctrl+,` 打开**设置**。
- `Tab` 和 `Shift+Tab` 移动焦点。
- `Enter` 或空格键激活当前控件。
- `Page Up`、`Page Down`、`Home` 和 `End` 用于浏览长文本。
- `Esc` 关闭通知对话框。

帮助目录和文章可以独立滚动。
